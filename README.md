DESIGN GOALS!

v.0.5a
Parametric Game Engine

The aim is to make a Game Engine which is Parametric.

It ought to be able to adhere to parametric models and visual models using shaders etc.

The main aim is that it ought to be able to create images very realistic looking, while still deeply ingrained in Parametric models (as in, that it ought to be possible to 3D-print, in 3D-print realism).

It ought to be able to apply basics of building planning such as showing why you should not put a brick building directly on top of a sand surface, while another material might be fine.

This project is not in it's infancy, but the code as is, can not be called ready, or even a version, at this point (it's pretty old).

I will keep updating it now that I have a computer strong enough for me to use a local LLM.

I will review all code before I upload it.
